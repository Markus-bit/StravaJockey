Guide

How it works

Draw a route on the map, choose how the activity should look, and download it as a GPX file.

  1. 1

    Draw your route

    Click on the map to place points along the way you want to go. A dashed line connects them. Use the location button to jump to where you are.

  2. 2

    Snap to road

    Press “Snap to road” to turn the points into a route that follows real roads and paths. Run uses footpaths, Bike uses cycle routes. The stats show distance, duration and elevation gain.

  3. 3

    Set the details

    Pick your average pace and how much it should vary, add heart rate data if you want it, and set the name, date and start time.

  4. 4

    Download the GPX

    Press “Download GPX”. The file contains GPS points with timestamps, elevation and heart rate, built from your settings. Long routes can take a few seconds.

Press “Clear” on the map to start over. Switching between Run and Bike re-snaps the route automatically. Next step: uploading your GPX file.
